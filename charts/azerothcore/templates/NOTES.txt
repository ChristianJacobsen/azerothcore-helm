AzerothCore, {{ .Values.flavor }} flavor ({{ .Chart.Name }} {{ .Chart.Version }}), game client 3.3.5a (build 12340)

THE FIRST INSTALL TAKES A FEW MINUTES:
{{- if eq .Values.clientData.source "download" }}
  1. client-data Job: downloads and unpacks the client data (about 1.1 GB)
{{- else }}
  1. client data: none (the data volume must hold dbc, maps, vmaps and mmaps already)
{{- end }}
{{- if .Values.dbInit.enabled }}
  2. db-init Job: creates the databases and runs dbimport
{{- end }}
  3. the worldserver waits for both, then loads the world

Watch the progress:
  kubectl -n {{ $ns }} get pods -w
{{- if eq .Values.clientData.source "download" }}
  kubectl -n {{ $ns }} logs -f job/{{ include "azerothcore.clientDataJobName" . }}
{{- end }}
{{- if .Values.dbInit.enabled }}
  kubectl -n {{ $ns }} logs -f job/{{ include "azerothcore.dbInitJobName" . }}
{{- end }}

CONNECT A GAME CLIENT (3.3.5a):
  kubectl -n {{ $ns }} get svc {{ $fullname }}-authserver {{ $fullname }}-worldserver
  1. Set realmlist.wtf in the client folder: set realmlist <authserver address>
  2. The realm list sends clients to {{ .Values.dbInit.realm.address }}:{{ include "azerothcore.realmPort" . }}
     (dbInit.realm.address and dbInit.realm.port). That must be an address
     where the client reaches the worldserver. For LAN or WAN players, run:
     helm upgrade {{ .Release.Name }} <chart> -n {{ $ns }} --reuse-values --set dbInit.realm.address=<LAN or WAN IP>

ACCOUNTS:
{{- if .Values.dbInit.accounts }}
  The db-init Job creates these accounts when they do not exist:
{{- range .Values.dbInit.accounts }}
    {{ .username | upper }} (gmlevel {{ .gmlevel | default 0 }})
{{- end }}
{{- else }}
  No accounts configured (dbInit.accounts). Create one in the worldserver console:
    kubectl -n {{ $ns }} attach -it deploy/{{ $fullname }}-worldserver -c worldserver
    account create <user> <password>
    account set gmlevel <user> 3 -1
  Detach with ctrl-p ctrl-q. Do not press ctrl-c: it stops the worldserver.
{{- end }}
{{- if .Values.gateway.enabled }}

GATEWAY API: the chart created one TCPRoute per game port. Point
realmlist.wtf and dbInit.realm.address at the Gateway address. You can set
authserver.service.type=ClusterIP and worldserver.service.type=ClusterIP.
{{- end }}
